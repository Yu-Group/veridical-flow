vflow · Stability analysis for data-science pipelines, with PCS.

A library for making stability analysis simple. Easily evaluate the effect of judgment calls to your data-science pipeline (e.g. choice of imputation strategy)!

Why use vflow?

Using vflows simple wrappers facilitates many best practices for data science, as laid out in the predictability, computability, and stability (PCS) framework for veridical data science. The goal of vflow is to easily enable data science pipelines that follow PCS by providing intuitive low-code syntax, efficient and flexible computational backends via Ray, and well-documented, reproducible experimentation via MLflow.

Computation Reproducibility Prediction Stability
Automatic parallelization and caching throughout the pipeline Automatic experiment tracking and saving Filter the pipeline by training and validation performance Replace a single function (e.g. preprocessing) with a set of functions and easily assess the stability of downstream results

Here we show a simple example of an entire data-science pipeline with several perturbations (e.g. different data subsamples, models, and metrics) written simply using vflow.

import sklearn
from sklearn.datasets import make_classification
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, balanced_accuracy_score
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

from vflow import Vset, build_vset, init_args

# initialize data
X, y = make_classification()
X_train, X_test, y_train, y_test = init_args(
    train_test_split(X, y),
    names=["X_train", "X_test", "y_train", "y_test"],  # optionally name the args
)

# subsample data: 3 bootstrap samples, reproducible thanks to the seed
subsampling_set = build_vset(
    "subsampling", sklearn.utils.resample, reps=3, seed=0, output_matching=True
)
X_trains, y_trains = subsampling_set(X_train, y_train)

# fit models
models = [LogisticRegression(), DecisionTreeClassifier()]
modeling_set = Vset(name="modeling", vfuncs=models, vfunc_keys=["LR", "DT"])
modeling_set.fit(X_trains, y_trains)
preds_test = modeling_set.predict(X_test)

# get metrics
binary_metrics_set = Vset(
    name="binary_metrics",
    vfuncs=[accuracy_score, balanced_accuracy_score],
    vfunc_keys=["Acc", "Bal_Acc"],
)
binary_metrics = binary_metrics_set.evaluate(preds_test, y_test)

Once we've written this pipeline, one call reports how stable the metrics (e.g. "Accuracy") are to our choice of subsampling or model:

from vflow import stability_report

report = stability_report(binary_metrics, compare="modeling")
print(report)  # or report.save("stability.html"), or show it in a notebook

which starts, for one run of the random data above, with:

- `binary_metrics` = Acc: 6 results, mean 0.86 (from 0.8 to 0.92).
- `binary_metrics` = Acc: most of the variation comes from `modeling` (76% of the variance).
- `binary_metrics` = Acc: `DT` is best in 3 of 3 perturbations (100%); next is `LR` (0%).
...

The report gives each metric separately: a summary, the share of the variance explained by each Vset, how often each model is best across the other perturbations, and the results by each Vset's choices. Its tables are DataFrames (report.variance, report.ranking, …) for further analysis.

veridical-flow for agents

Full guide: vflow for agents.

agents/ is a Claude Code plugin that brings PCS to analyses done by AI agents. Its veridical-flow skill takes a yes/no question about a dataset ("does BMI affect diabetes progression?") and has independent analyst agents answer it many times: on the real data, on copies with every column shuffled (where the true answer is "no"), and under perturbations that should not change the answer (unrelated extra columns, anonymized or misleading column names, a question that leans toward one answer). It then reports whether the "yes" stands apart from the answers on shuffled data and holds across the perturbations. Every run is a saved folder that can be opened and rerun.

claude --plugin-dir agents
> Use veridical-flow to check whether bmi affects target in diabetes.csv

The skill bundles three standard-library scripts: prepare.py writes the blinded analyst workspaces, progress.py shows a progress bar with elapsed time and an ETA while analysts work, and summarize.py scores the answers. Each workspace is a full agent analysis, so start small; the skill asks before launching more than about 20 analyst runs and reports progress after every batch.
